# Обмен веществ

Логическая игра в браузере. У каждого предмета четыре свойства — **вес**, **тепло**,
**влага** и **упругость**, — а у игрока ровно один глагол: **обменять одно свойство
между двумя предметами**.

Мокрое не горит. Тяжёлое тонет. Податливое провисает. Твоё тело — тоже предмет,
и его свойства можно отдать, чтобы растопить лёд, и остаться холодным до конца комнаты.

## Запуск

```bash
npm run dev          # http://localhost:4173
```

Игра статическая: `index.html` + ES-модули. Ни сборки, ни зависимостей, ни бэкенда.

Если открыть `index.html` напрямую через `file://`, браузер заблокирует ES-модули —
поэтому нужен любой статический сервер.

## Проверки

```bash
npm test         # все восемь комнат решаются (поиск в ширину по состояниям)
npm run playtest # прогон интерфейса в jsdom: клики, победа, отмена, прогресс
npm run shots    # отрендерить комнаты в preview/room-N.png
```

`npm test` — не проверка «на глаз»: он перебирает состояния комнаты и находит
кратчайшее решение. Если после правок головоломка станет непроходимой, тест упадёт.

## Восемь комнат

| № | Комната | Закон комнаты |
|---|---------|----------------|
| 1 | Свеча | Верёвку держит тепло, а не огонь. Кувшин с водой — ловушка. |
| 2 | Утопленник | Лёгкое всплывает. Двум тяжёлым вещам нужны два лёгких донора. |
| 3 | Ледник | Котёл отдаст тепло один раз. Второй засов — собой. |
| 4 | Смола | Высуши смолу и нагрузи рычаг. Просто груз не поможет. |
| 5 | Порох | Мокрое не горит, сколько ни грей. Порядок важен. |
| 6 | Мост | Верёвке нужны жёсткость и сухость, но не вес. |
| 7 | Метаморфоза | Глина → кирпич: сухость, жар, плотность от трёх разных вещей. |
| 8 | Кузница | Четыре свойства — четыре разных донора. |

## Почему тупиков не бывает

Правила комнаты — **чистая функция**: они только читают значения и говорят,
выполнены условия или нет. Ничего не «портится», не сгорает и не расходуется
безвозвратно. Обмен — это перестановка чисел, а перестановку всегда можно отменить.
Поэтому в игре нет проигрыша, есть только поиск.

Именно из-за этого работает подсказка «условия двери»: она показывает ровно то,
чего не хватает, и никогда не врёт.

## Устройство

```
index.html          разметка и подключение модулей
styles.css          мастерская: воск, латунь, бумага, свет свечи
src/engine.js       состояние, обмены, оценка, поиск решений
src/rooms.js        восемь комнат: предметы, числа, условия
src/art.js          рисунки предметов (SVG)
src/ui.js           сцена, каналы, инспектор, печать, прогресс
src/main.js         точка входа
tests/              проверка проходимости, игровой прогон, скриншоты
server.mjs          статический сервер без зависимостей
```

### Комната — это данные, а не код

```js
{
  id: 1,
  name: 'Свеча',
  objects: [
    { id: 'rope', art: 'rope', pos: {…},
      stats: { mass: 25, heat: 20, moisture: 30, give: 62 } },
  ],
  evaluate(state) {
    const rope = state.objects.find(o => o.id === 'rope');
    return {
      solved: rope.stats.heat >= 70 && rope.stats.moisture <= 32,
      status: [
        { ok: rope.stats.heat >= 70, text: 'верёвка раскалена' },
        { ok: rope.stats.moisture <= 32, text: 'верёвка сухая' },
      ],
    };
  },
}
```

Новую комнату можно добавить, не трогая движок и интерфейс. Достаточно дописать
объект в `ROOMS` — `npm test` сразу скажет, решается ли она.

## Управление

- **Канал** — панель слева или цифры 1–4 (вес, тепло, влага, упругость).
- **Обмен** — щёлкни донора, затем получателя.
- **Ctrl+Z** — отменить ход. **Esc** — сбросить выбор.
- Наведение на предмет показывает его шкалы и описание («ледяной, насквозь мокрый»).
