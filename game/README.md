# НЕ СПИ

Мальчик. Двухэтажный дом. Родители в командировке. Ночь не кончается.

Игра про то, что в доме кто-то есть, а тебе восемь, и ты не можешь уснуть.

## Запуск

```bash
cd game
npm run dev        # http://localhost:4173
npm test           # 149 проверок без браузера
npm run build      # dist/ + бюджеты
```

Зависимостей для запуска нет: `server.mjs` — 40 строк на `node:http`,
three.js лежит в `vendor/`, минифицированный, и не тянет ничего из сети.

## Что уже сделано (M1)

- **Дом**: 11 комнат, 154 м², 4 уровня (подвал, два этажа, чердак), 14 дверей,
  6 окон, 11 источников света. Все размеры и высоты — реальные, в метрах.
- **Планировка проверена тестами**: комнаты не налезают друг на друга,
  мебель не стоит в стенах и не перекрывает двери, дом связный, подвал→чердак
  проходится за 91 секунду крадучись и за 29 бегом.
- **Мебель**: 55 шаблонов (кровать, шкаф, стол, холодильник, ванна, котёл,
  стеллаж с банками, стремянка, люк в подвал…), расставлено 66 предметов
  и 33 мелочи. В каждой комнате 6–10 активных предметов и 2–5 мелочей.
- **Мальчик**: воксельная кукла 1.22 м, детские пропорции (голова 19% роста),
  8 частей тела на пивотах, 10 состояний (идёт, крадётся, бежит, слушает,
  прячется, спит, тянется…), моргание, дрожь от страха, дыхание.
- **Управление под телефон**: два аналоговых стика — левый идти, правый смотреть
  (зона захвата — половина экрана, палец не обязан попадать в кружок, база едет
  за пальцем). Кнопки: фонарь, присесть, слушать, бежать, карта, действие.
  Направление движения берётся из матрицы камеры и проверяется тестом на 360°.
- **Две сцены**: разрез дома на canvas 2D (карта, грузится первой) и 3D-комната
  на three.js. Камера от третьего лица через плечо: мальчика видно, камера не
  проходит сквозь стены (поджимается, а в узкой комнате поднимается выше).
- **Бюджеты**: 63 КБ gzip своего кода + 187 КБ three.js. Комната — 40 draw call,
  1.5–2 тыс. треугольников.

### Почему это работает на телефоне

1. **Никакой физики.** Дом — граф, ходьба — по прямым с обходом мебели.
   Мальчик не может застрять в геометрии, потому что геометрия не участвует
   в движении.
2. **Один вызов на материал.** Вся статика комнаты слита по цветам:
   40 draw call на комнату вместо ~150.
3. **Рендер в 0.75× и апскейл.** На телефоне разница не видна, работа GPU вдвое меньше.
4. **Карта грузится первой.** Пока three.js инициализируется, игрок уже видит дом.
5. **Всё в метрах.** Выключатель на 1.15 м, глазок на 1.45 м, верхняя полка на
   1.68 м, мальчик 1.22 м. Отсюда вся механика «достать = поставить мебель» —
   и она не выдумана, а посчитана.

### Как проверяется без браузера

Браузера в песочнице нет, поэтому три уровня проверок:

- **Геометрия** (`tests/house.test.mjs`): прямоугольники комнат, пересечения
  мебели, дверные проёмы, высоты, достижимость.
- **Меши** (`tests/render.test.mjs`): строятся настоящие three.js-геометрии в node,
  проверяется, что нет NaN, нет индексов вне диапазона и не превышены бюджеты.
- **Поведение** (`tests/world.test.mjs`, `tests/input.test.mjs`): жесты, ходьба,
  переходы, время, шкалы.

Проверка «страшно ли» так не делается — её придётся делать на телефоне.
